# Wiztoonz Module Builder

A professional academic curriculum management tool designed for Wiztoonz Faculty. 

## Features
- **Module Builder**: Drag and drop modules to create custom curriculum combinations.
- **Assessment Management**: Edit and refine assessment briefs, tools, and methodologies.
- **Combined PDF Export**: Generate comprehensive curriculum reports with a single click.
- **Persistence**: Edits and builder states are saved locally in the browser.
- **Premium UI**: Modern glassmorphism design with smooth animations.

## Local Development
Simply open `index.html` in any modern web browser or serve it using a local server:
```bash
python3 -m http.server 8000
```

## Deployment
This project is ready to be hosted on **Vercel**, **GitHub Pages**, or **Netlify** as a static site.
